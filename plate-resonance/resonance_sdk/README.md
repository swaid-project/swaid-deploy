# Resonance SDK (Legacy C++)

## Status: ⚠️ Deprecated
This folder is now deprecated.

As per the **"Smart Client, Synchronized Core"** paradigm, the Python Human Interface now uses native **`pyzmq`** to communicate with the C++ Core via standard JSON. This removes the need for a C++ client wrapper and simplifies the build system.

## Contents
This directory is preserved only for historical reference of the original ZeroMQ protocol design.

# Soundcard Driver Component

Real-time audio processing and dynamic routing for the SWAID Plate Resonance project.

## Role
This component handles the "DSP Layer." It generates high-precision sine waves for the resonance transducers and mixes them with the generative music generated by the embedded `libpd` engine.

## Key Features

- **Multi-Stream Discovery**: Automatically scans for soundcards by name substrings (e.g., "USB Audio", "HDMI").
- **Dynamic Routing**: Supports isolated output streams. You can route Music to HDMI and Vibrations to USB Soundcard simultaneously.
- **Sine Wave Bank**: 8 atomic oscillators with thread-safe control.
- **DSP Safety (100ms Fade)**: Hardcoded linear interpolation on all amplitude changes. Prevents zero-crossing pops and prevents mechanical damage to transducers.
- **Safety Bounds Check**: Automatically detects the channel count of the physical device and prevents buffer overflows if the software requests more generators than the hardware supports.

## Execution Flow
1. **`audioCallback`**: Used when music and transducers share one 8-channel device.
2. **`musicCallback`**: Used when music is isolated (e.g., HDMI 2-channel).
3. **`transducerCallback`**: Used when vibrations are isolated (e.g., USB 8-channel).

## Configuration
Controlled via `system_config.json`:
- `transducer_device_name`
- `music_device_name`
- `music_channels`
- `transducer_channels`
